# v1.11 更新说明 - 周期性回顾功能

## 新增功能

### Phase 3.0: 周期性回顾

**核心功能**：在头部导航栏添加"回顾"Tab，提供本周/本月的数据统计和AI总结。

**统计维度**：
1. **本周笔记数量** - 本周（周一至周日）记录的笔记总数
2. **本月笔记数量** - 本月1号至今的笔记总数
3. **涉及分类数** - 本周笔记覆盖的分类数量
4. **分类分布图** - 可视化展示各分类的占比（进度条形式）
5. **待处理提醒** - 如果收集箱有未整理的笔记，显示警告提示

**AI总结功能**：
- 点击"🤖 AI 生成本周回顾总结"按钮
- AI分析本周所有笔记的内容和分类
- 生成200字以内的温暖回顾报告
- 包含：主要话题、思维趋势、值得深入的方向、鼓励性结语

## 技术实现

### 数据计算逻辑

```javascript
// 本周范围：本周一零点至今
var now = new Date();
var weekStart = new Date(now.getFullYear(), now.getMonth(), now.getDate() - now.getDay()).getTime();

// 本月范围：本月1号零点至今
var monthStart = new Date(now.getFullYear(), now.getMonth(), 1).getTime();

// 筛选本周笔记
var weekNotes = store.notes.filter(function(n) {
  return new Date(n.updatedAt).getTime() >= weekStart;
});
```

### 分类分布渲染

```javascript
// 统计每个分类的数量
var catCounts = {};
weekNotes.forEach(function(n) {
  var c = n.category || "未分类";
  catCounts[c] = (catCounts[c] || 0) + 1;
});

// 按数量降序排列
var sortedCats = Object.keys(catCounts).sort(function(a, b) {
  return catCounts[b] - catCounts[a];
});

// 渲染进度条
sortedCats.forEach(function(c) {
  var pct = Math.round(catCounts[c] / weekNotes.length * 100);
  // 动态宽度 = pct%
});
```

## 使用场景

### 场景1：周五下午复盘
- 打开"回顾"Tab查看本周数据
- 看到分类分布图，发现自己这周主要在研究产品设计
- 点击AI生成总结，获得温暖的鼓励和下一步建议
- 带着清晰的认知进入周末

### 场景2：月度总结准备
- 查看"本月概览"了解整体情况
- 结合每周回顾，梳理一个月的思考脉络
- 导出或截图保存作为月度报告素材

### 场景3：发现思维盲点
- 通过分类分布图发现自己某类笔记特别多
- AI总结指出重复出现的主题
- 意识到需要拓展新的思考方向
