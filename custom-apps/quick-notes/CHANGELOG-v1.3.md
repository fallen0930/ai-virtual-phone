# v1.3 更新说明 - 快捷模板系统

## 新增功能

### 1. 快捷模板选择器
- 点击底部工具栏的 📋 按钮打开模板选择器
- 或在编辑面板中点击"使用模板"按钮

### 2. 预设模板（5个）
- **🐛 Bug 记录**：现象、复现步骤、期望结果
- **💡 灵感想法**：背景、核心点、可能价值
- **✅ 待办事项**：任务、截止时间、优先级
- **🤔 反思总结**：事件、感受、收获、改进
- **📚 学习笔记**：主题、关键概念、疑问

### 3. AI 提示词复制 + 粘贴解析
- 点击"📋 复制AI提示词"按钮
- 将提示词粘贴给 ChatGPT/Claude/Kimi 等 AI，让它按格式生成模板
- **在模板选择器中直接粘贴 AI 返回的 JSON**
- 点击"解析并保存为模板"按钮即可保存

### 4. 自定义模板导入
- **JSON 文件导入**：直接导入符合格式的 JSON 文件
- **粘贴解析**：直接在文本框粘贴其他 AI 生成的 JSON（推荐方式）
- **手动创建引导**：提供详细的手动创建模板教程

### 5. 我的模板管理
- 导入的模板会显示在"我的模板"区域
- 点击即可应用到当前编辑面板
- 数据保存在 IndexedDB，永久保留（已修复保存问题）

## 使用方法

### 快速开始
1. 点击底部 📋 按钮打开模板选择器
2. 选择一个预设模板或自定义模板
3. 编辑面板会自动填充模板内容
4. 修改后保存即可

### 从其他 AI 导入模板（推荐）
1. 点击"📋 复制AI提示词"
2. 将提示词粘贴给 ChatGPT/Claude/Kimi 等 AI
3. 让 AI 根据你的需求生成模板 JSON
4. 复制 AI 返回的 JSON 内容
5. 回到模板选择器，在"粘贴 AI 生成的 JSON"文本框中粘贴
6. 点击"解析并保存为模板"按钮
7. 新模板会出现在"我的模板"中

### 导入 JSON 文件
1. 将 AI 生成的 JSON 保存为 .json 文件
2. 点击"📁 导入JSON文件"选择文件
3. 模板会自动保存到"我的模板"

### 手动创建模板
1. 点击"✏️ 手动创建模板"查看指南
2. 按照指引创建自己的模板
3. 使用在线 JSON 工具格式化后导入

## 技术细节

### 模板格式
```json
{
  "name": "模板名称",
  "icon": "一个emoji",
  "desc": "一句话描述用途（20字以内）",
  "title": "默认标题前缀（可选）",
  "text": "模板正文内容，用【部分名】标记各个段落",
  "category": "默认分类（可选）",
  "tags": ["标签1", "标签2"]
}
```

### 数据存储
- 自定义模板存储在 `meta` 集合的 `customTemplates` 字段
- 与分类清单、默认角色一起保存
- **已修复保存逻辑，现在刷新后模板不会丢失**
- 支持应用内换包更新，数据不丢失

## v1.3.2 修复（本次）

### 问题修复

#### 1. 模板保存后消失
**原因**：`saveMeta()` 函数没有保存 `customTemplates` 字段  
**解决**：在保存时包含 `customTemplates: store.customTemplates || []`

#### 2. 选择模板后卡死
**原因**：`applyTemplate()` 同时调用 `closeSheets()` 和 `openEditor("")` 导致冲突  
**解决**：先关闭选择器，延迟150ms后再打开编辑器

#### 3. manifest.extensions.events 错误
**原因**：沙盒环境不支持某些事件监听和文件解析  
**解决**：移除"从文档生成模板"功能（doc/docx/md 都无法可靠解析）

#### 4. md文件导入失败
**原因**：文本文件不是JSON格式，无法作为模板解析  
**解决**：只保留JSON文件导入，移除文档生成功能

### 功能优化
- **简化导入流程**：只保留 JSON 文件导入和粘贴解析两种方式
- **优化提示词**：提供更清晰的示例和格式要求
- **添加手动创建引导**：帮助用户理解如何自己创建模板
- **改进错误提示**：更友好的错误信息和解决方案

### 已知限制
- 沙盒环境无法解析 doc/docx/md/txt 等非JSON格式文件
- 必须通过 AI 生成 JSON 或手动创建 JSON 格式
- 单次最多支持 20 个自定义模板
