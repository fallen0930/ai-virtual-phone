# v1.4 更新说明 - 双向链接功能

## 新增功能

### 双向链接（知识网络）

现在可以在笔记之间建立引用关系，形成知识网络。

#### 使用方法

**方式一：手动输入（适合记得标题时）**
1. 在笔记内容中使用 `[[笔记标题]]` 语法
2. 例如：`这个想法和 [[产品架构设计]] 有关联`
3. 系统会自动检测并解析链接

**方式二：搜索选择（推荐，不用记标题）**
1. 点击编辑面板中的" 插入链接到笔记"按钮
2. 在弹出的列表中搜索或浏览笔记
3. 点击要链接的笔记
4. 自动在光标位置插入 `[[标题]]`

#### 查看链接关系

1. **正向链接**
   - 打开笔记时，底部会显示"🔗 引用的笔记"
   - 点击链接可直接跳转到被引用的笔记

2. **反向链接**
   - 显示"️ 被以下笔记引用"
   - 了解哪些笔记引用了当前笔记
   - 发现知识的关联性和演进路径

3. **列表标识**
   - 有链接的笔记会在卡片上显示 🔗 徽章
   - 数字表示引用的笔记数量

#### 示例场景

```
笔记A: "今天想到了一个新的交互方案，参考 [[用户体验优化]] 里的原则"
       ↓ 创建了到"用户体验优化"的链接

笔记B: "用户体验优化"
       ↓ 显示被"笔记A"引用

点击任意链接即可在相关笔记间快速跳转
```

### UI 优化

- **模板选择器适配**：添加安全区域支持，避免顶部贴边
- **关闭按钮优化**：增加间距，防止误触
- **链接插入更便捷**：可视化搜索选择，无需记忆标题

### 技术实现

- **自动解析**：保存笔记时自动扫描 `[[...]]` 语法
- **智能匹配**：支持按标题或ID查找目标笔记
- **实时查询**：动态计算正向和反向链接关系
- **数据存储**：在笔记的 `links` 字段中存储引用的ID列表
- **可视化选择器**：支持搜索、预览、一键插入

## 使用技巧

### 构建知识网络
1. 写新笔记时，思考"这和之前的哪些想法有关联？"
2. 用"🔗 插入链接"按钮搜索并选择相关笔记
3. 定期查看反向链接，发现知识聚类

### 常见用法
- **项目关联**：`[[项目A需求]]` `[[技术方案]]`
- **概念引用**：`[[设计原则]]` `[[最佳实践]]`
- **任务依赖**：`[[前置任务]]` `[[后续计划]]`
- **灵感溯源**：`[[原始想法]]` `[[演进过程]]`

## v1.4.1 修复（本次）

### 问题修复

#### 1. 模板选择器顶部贴边+无法关闭
**原因**：未考虑刘海屏/灵动岛的安全区域  
**解决**：
- 添加 `padding-top:env(safe-area-inset-top, 0px)` 
- 关闭按钮增加 `margin-top:4px`
- 头部使用 `max(14px, env(safe-area-inset-top, 14px))` 确保最小间距

#### 2. 链接笔记不方便
**原因**：需要手动输入完整标题，容易忘记  
**解决**：
- 添加"🔗 插入链接到笔记"按钮
- 弹出笔记选择器，支持搜索和浏览
- 点击笔记自动插入 `[[标题]]` 格式
- 最多显示50条笔记，避免列表过长
