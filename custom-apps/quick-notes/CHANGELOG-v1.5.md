# v1.5 更新说明 - 智能推荐功能

## 新增功能

### 💡 智能推荐

打开笔记时，系统会自动分析并推荐最相关的其他笔记，帮助你发现知识关联。

#### 推荐算法（多维度评分）

系统会综合以下6个维度计算相似度得分：

1. **分类相同** (+30分)
   - 同一分类下的笔记优先推荐
   - 例如：都是"技术问题"分类

2. **标签重叠** (+20分/个，最多60分)
   - 共享标签越多，相关性越高
   - 例如：都有"bug"、"待排查"标签

3. **内容关键词匹配** (+5分/个，最多50分)
   - 自动提取文本中的关键词
   - 过滤停用词（的、了、是等）
   - 匹配共同出现的词汇

4. **链接关系** (+40分)
   - 直接引用或被引用的笔记
   - 最强的关联信号

5. **共同引用** (+15分/个，最多30分)
   - 引用了相同目标笔记的其他笔记
   - 发现知识网络中的聚类

6. **时间接近** (+10分)
   - 7天内更新的笔记
   - 可能是相关的工作流

#### UI 展示

- 在编辑面板底部显示" 相关推荐"区域
- 最多显示5条最相关的笔记
- 每条显示：
  - 笔记标题
  - 推荐理由（最多2个）
  - 相似度得分
- 点击卡片直接跳转到该笔记

#### 示例

```
当前笔记: "修复登录接口的Token过期问题"
分类: 技术问题
标签: [bug, 认证]

推荐结果:
1.  OAuth2.0实现方案 (得分:95)
   同分类: 技术问题 · 共同标签: 认证
   
2. 🔗 用户会话管理优化 (得分:70)
   内容相关: token, session, 过期
   
3. 🔗 前端登录状态同步 (得分:55)
   被引用 · 时间接近
```

### 技术实现

**关键词提取**
- 简单的中文分词（按空格和标点分割）
- 过滤常见停用词
- 去重后取前30个关键词

**相似度计算**
- 多维度加权评分
- 排除当前笔记自身
- 只返回得分>0的笔记

**性能优化**
- 只在打开编辑面板时计算一次
- 限制推荐数量为5条
- 避免频繁遍历所有笔记

## 使用场景

### 发现相关知识
- 写新笔记时查看推荐，避免重复记录
- 找到之前写过的相关想法

### 构建知识网络
- 通过推荐发现遗漏的链接
- 补充双向链接关系

### 回顾工作流
- 查看最近相关的笔记
- 追踪项目进展和思路演进
