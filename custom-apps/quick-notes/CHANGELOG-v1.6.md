# v1.6 更新说明 - 时间线视图

## 新增功能

### 时间线视图（Phase 2.2）
- **新增"时间线"Tab**：位于头部导航栏，在"想法"和"分析"之间
- **智能时间分组**：自动将笔记按时间段分组显示
  - 📅 今天
  - ⏮️ 昨天
  - 📆 本周
  - 🗓️ 本月
  - 🕰️ 更早
- **可视化时间轴**：左侧带时间轴线和小圆点，清晰展示思考历程
- **卡片式展示**：每个笔记显示日期、标题、分类徽章、前80字摘要
- **点击打开编辑**：点击任意时间线卡片即可进入编辑模式
- **实时更新**：切换Tab即时渲染，无需刷新

## 使用方法

### 查看时间线
1. 点击顶部的"时间线"Tab按钮
2. 自动按时间分组显示所有笔记
3. 每组显示该时间段内的笔记数量
4. 点击任意卡片打开编辑面板

### 时间线 vs 列表视图
- **列表视图**：适合快速浏览、搜索、筛选特定分类的笔记
- **时间线视图**：适合回顾思考历程、发现思维演进脉络、按时间顺序整理

## 技术细节

### 时间分组逻辑
```javascript
// 基于 updatedAt 字段进行时间分组
- 今天：updatedAt >= 今日零点
- 昨天：昨日零点 <= updatedAt < 今日零点
- 本周：本周一零点 <= updatedAt < 昨日零点
- 本月：本月一号零点 <= updatedAt < 本周一零点
- 更早：updatedAt < 本月一号零点
```

### CSS样式设计
- 时间轴线：使用渐变背景色营造视觉深度
- 时间节点：实心圆点 + 外发光效果
- 卡片交互：hover时轻微缩放反馈
- 响应式布局：适配不同屏幕尺寸

### 性能优化
- 仅在当前视图需要时渲染时间线
- 复用现有笔记数据，无额外数据库查询
- 纯前端计算，不消耗token

## 已知限制

- 时间线视图暂不支持搜索和筛选（后续版本会添加）
- 大量笔记时（>500条）可能滚动较慢（建议定期归档旧笔记）
- 暂时不支持按创建时间排序（当前使用更新时间）

## v1.6.1 修复（本次）

### 问题修复
1. **renderList()未处理timeline视图**
   - 原因：条件判断只检查了anas视图
   - 解决：添加`if (store.view === "timeline") return renderTimeline();`

2. **renderTabs()缺少时间线Tab状态更新**
   - 原因：忘记更新qnTabTimeline的data-on属性
   - 解决：添加时间线Tab的状态同步逻辑

3. **缺少时间线CSS样式**
   - 原因：只实现了JS逻辑，未添加对应的CSS类
   - 解决：添加完整的`.qn-timeline-*`系列样式类

- 时间线卡片摘要限制为80字（列表视图为220字），更简洁
