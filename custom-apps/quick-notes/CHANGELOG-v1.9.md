# v1.9 更新说明 - 状态筛选优化

## 问题背景

用户反馈："我点击了已整理，那我的笔记就消失了，这个收纳箱和已整理有啥意义"

**核心问题**：
1. 将笔记标记为"已整理"后，从默认列表中消失，用户找不到
2. "收集箱"、"已整理"、"归档"三个状态的区别和使用场景不清晰
3. 缺少查看不同状态笔记的入口

## 解决方案

### 1. 添加状态筛选 Chips

在分类筛选区域新增三个状态按钮：

```
[全部 7] [收集箱 3] [已整理 2] [归档 2] [产品想法 2] [参考/灵感 1] ...
```

**使用方式**：
- **全部** - 显示所有笔记（不管状态）
- **收集箱** - 只显示待处理的笔记（`status === "inbox"`）
- **已整理** - 只显示已完成整理的笔记（`status === "sorted"`）
- **归档** - 只显示历史存档的笔记（`status === "archived"`）

### 2. 明确三个状态的含义

在编辑面板的状态选择器旁添加说明文字：

> **状态** （收集箱=待处理，已整理=已完成，归档=历史存档）

**工作流程建议**：
```
新建笔记 → 收集箱（默认）
    ↓
AI 整理 / 手动归类 → 已整理
    ↓
长期不再需要 → 归档
```

**各状态的使用场景**：

| 状态 | 含义 | 使用场景 | 可见性 |
|------|------|----------|--------|
| **收集箱** | 待处理 | 刚记录的想法，还未分类或整理 | 默认列表 + "收集箱"筛选 |
| **已整理** | 已完成 | AI 已归类打标签，或手动整理完毕 | "已整理"筛选 + 对应分类筛选 |
| **归档** | 历史存档 | 过时的想法、已完成的项目记录 | "归档"筛选 |

### 3. 技术实现

**数据结构扩展**：
```javascript
// renderChips() 中新增状态计数
var inbox = store.notes.filter(function (n) { return n.status === "inbox"; }).length;
var sorted = store.notes.filter(function (n) { return n.status === "sorted"; }).length;
var archived = store.notes.filter(function (n) { return n.status === "archived"; }).length;

// 生成状态 chips
html += chip("status:inbox", "收集箱", inbox);
html += chip("status:sorted", "已整理", sorted);
html += chip("status:archived", "归档", archived);
```

**筛选逻辑更新**：
```javascript
function filteredNotes() {
  var list = store.notes.filter(function (n) {
    // 状态筛选（新增）
    if (store.cat === "status:inbox") { if (n.status !== "inbox") return false; }
    else if (store.cat === "status:sorted") { if (n.status !== "sorted") return false; }
    else if (store.cat === "status:archived") { if (n.status !== "archived") return false; }
    // 分类筛选
    else if (store.cat.indexOf("c:") === 0) { 
      if ((n.category || "未分类") !== store.cat.slice(2)) return false; 
    }
    
    // 搜索筛选
    if (q) { /* ... */ }
    return true;
  });
}
```

**命名规范**：
- 状态筛选使用前缀 `status:` 避免与分类名冲突
- 分类筛选使用前缀 `c:` 保持不变
- 空字符串表示"全部"

### 4. UI 布局

```
──────────────────────────────────────────────┐
│ 随想笔记          [想法] [时间线] [分析]       │
│ 共 7 条想法 · 收集箱 3 · 已整理 2 · 归档 2     │
│ 🔍 搜索标题 / 正文 / 标签                      │
│ [全部 7] [收集箱 3] [已整理 2] [归档 2]        │
│ [产品想法 2] [参考/灵感 1] [其他 2]            │
└──────────────────────────────────────────────
```

**设计原则**：
- 状态筛选在前（工作流维度）
- 分类筛选在后（内容维度）
- 每个chip显示数量，一目了然

## 使用示例

### 场景1：日常记录
1. 新建笔记，自动落入"收集箱"
2. 点击"收集箱"chip查看所有待处理的笔记
3. 逐条让AI整理或手动归类
4. 整理完成后状态变为"已整理"，从收集箱消失

### 场景2：批量整理
1. 点击"收集箱"看到5条待处理笔记
2. 点击"AI 批量处理"一键整理
3. 整理完成后切换到"已整理"查看结果
4. 确认无误后继续下一条

### 场景3：查找历史记录
1. 记得上个月写过某个想法，但不知道分类
2. 点击"归档"查看所有历史存档
3. 结合搜索功能快速定位
4. 找到后可以改回"已整理"重新激活

### 场景4：按分类查看
1. 想看所有"产品想法"相关的笔记
2. 点击"产品想法"chip
3. 显示该分类下的所有笔记（包括收集箱、已整理、归档）
4. 不受状态限制，专注于内容主题

## 后续优化方向

1. **状态+分类组合筛选** - 例如"收集箱中的产品想法"
2. **批量修改状态** - 选中多条笔记一次性改为"已整理"或"归档"
3. **自动归档规则** - 超过30天未更新的"已整理"笔记自动归档
4. **状态流转统计** - 显示本周整理了多少条、归档了多少条
5. **快捷操作** - 在笔记卡片上直接切换状态，无需打开编辑面板
