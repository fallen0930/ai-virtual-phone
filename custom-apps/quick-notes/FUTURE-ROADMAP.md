# 随想笔记 · 后续优化路线图

基于「碎片化记录 → 系统化整理 → 自我提升」的核心目标，按优先级分阶段推进。

---

## Phase 1: 基础增强（已完成 / 进行中）

### ✅ v1.1 - 附件上传与 AI 分析（当前版本）
- **功能**：
  - 支持上传 doc/docx、zip、txt、md、png、jpg 等格式文件
  - 单文件限制 5MB，存储在 IndexedDB（base64）
  - 「分析附件」开关控制是否对 txt/md/图片进行内容提取
  - 笔记卡片显示附件数量标识
- **技术要点**：
  - FileReader API 读取文件为 base64
  - txt/md 直接解码文本传给 AI
  - 图片暂不支持 OCR（需宿主支持 vision）
  - doc/docx/zip 仅存储元数据，无法分析内容

### 📋 v1.2 - 语音输入（待实现）
- **功能**：
  - 在编辑面板添加「语音输入」按钮
  - 调用 `ai.speechToText` 将语音转为文字
  - 自动追加到正文末尾或替换选中内容
- **前提**：宿主需支持 `ai.speechToText` 权限
- **价值**：快速记录想法，适合通勤/运动等场景

### 📋 v1.3 - 快捷模板
- **功能**：
  - 预设几种常用笔记模板：
    - 🐛 Bug 记录（现象、复现步骤、期望结果）
    - 💡 灵感想法（背景、核心点、可能价值）
    - ✅ 待办事项（任务、截止时间、优先级）
    - 🤔 反思总结（事件、感受、收获、改进）
  - 新建笔记时可选择模板，自动填充结构
- **价值**：降低记录门槛，提高信息结构化程度

## Phase 2: 知识管理

### 📋 v2.0 - 双向链接
- **功能**：
  - 在笔记正文中使用 `[[笔记ID]]` 或 `[[笔记标题]]` 语法引用其他笔记
  - 点击链接跳转到对应笔记
  - 在笔记详情页显示「被哪些笔记引用」
- **技术要点**：
  - 解析正文中的 `[[...]]` 模式
  - 建立反向索引表
  - 可能需要新增 `references` 集合存储关系
- **价值**：形成知识网络，发现想法之间的关联

### 📋 v2.1 - 智能推荐
- **功能**：
  - 打开某条笔记时，AI 分析其内容
  - 推荐相关的历史笔记（基于语义相似度）
  - 显示推荐理由（如「都提到了 XX 问题」）
- **技术要点**：
  - 需要 embedding 能力或关键词匹配
  - 可先用简单的标签/分类重叠度作为启发式
- **价值**：避免重复思考，激活沉睡的知识

### 📋 v2.2 - 时间线视图
- **功能**：
  - 新增「时间线」Tab，按时间轴展示所有笔记
  - 可按天/周/月缩放
  - 鼠标悬停显示笔记摘要
  - 支持快速跳转到某个时间段
- **价值**：直观看到想法的演进过程，发现思维轨迹

### 📋 v2.3 - 导出功能
- **功能**：
  - 支持导出单条笔记为 Markdown
  - 支持批量导出某个分类的所有笔记
  - 支持导出全部笔记库（带目录结构）
  - 可选：导出为 PDF（需引入 jsPDF 等库）
- **价值**：方便归档和分享，避免数据锁定

## Phase 3: 自我提升辅助

### 📋 v3.0 - 周期性回顾
- **功能**：
  - 每周/每月自动生成回顾报告
  - 内容包括：
    - 📊 统计数据：本周新增 X 条想法，Y 条已整理，Z 条已归档
    - 🔥 高频话题：出现最多的标签/关键词
    - ⏳ 未完成事项：收集箱里超过 7 天未处理的
    - 💬 AI 点评：基于本周内容的整体观察和建议
  - 报告以「分析记录」形式保存，可发给角色讨论
- **技术要点**：
  - 定时任务触发（可用 `setTimeout` 模拟，或依赖宿主的事件系统）
  - AI 批量分析 + 统计聚合
- **价值**：强制反思，避免「只记不看」

### 📋 v3.1 - 目标追踪
- **功能**：
  - 新增「目标」集合，可创建长期目标（如「掌握 React 性能优化」）
  - 笔记可关联到一个或多个目标
  - 目标详情页显示：
    - 相关笔记列表
    - 进度评估（AI 根据笔记内容判断进展）
    - 下一步建议
  - 仪表盘显示所有目标的完成度
- **价值**：将碎片想法对齐到长期方向，避免散焦

### 📋 v3.2 - 模式识别
- **功能**：
  - AI 定期扫描整个笔记库，发现思维模式：
    - 「你最近 3 次提到 XX 问题，但都没有深入」
    - 「这类『想做但没做』的想法出现了 5 次，值得系统化」
    - 「你在 A 领域记录很多，但 B 领域几乎空白，是否失衡？」
  - 以「洞察卡片」形式呈现，用户可标记「已读」「忽略」
- **技术要点**：
  - 需要较强的 NLP 能力（聚类、主题建模）
  - 可先用简单的关键词频率 + 规则引擎
- **价值**：发现盲点，促进系统性思考

## Phase 4: 协作与分享

### 📋 v4.0 - 角色深度互动
- **功能**：
  - 「邀请角色阅读我的笔记库」
  - 角色定期（如每周）主动生成一份「读书报告」
  - 可与角色就某条笔记展开多轮对话，对话记录保存在笔记的「讨论区」
- **价值**：获得外部视角，激发新想法

### 📋 v4.1 - 一键分享到聊天室
- **功能**：
  - 在笔记详情/编辑面板添加「发到聊天室」按钮
  - 选择角色后，自动将笔记内容（含附件摘要）发送给该角色
  - 角色的回复可追加到笔记的「讨论记录」中
- **价值**：快速获得反馈，深化思考

### 📋 v4.2 - 公开分享（脱敏）
- **功能**：
  - 生成可分享的只读链接（需后端支持）
  - 自动脱敏敏感信息（如人名、公司名）
  - 可选择分享单条笔记或整个分类
  - 访问者无需登录即可查看
- **价值**：与他人交流，获取外部反馈

## 技术债务与优化

### 🔧 性能优化
- **大附件处理**：当前 base64 存储会导致内存占用高，考虑：
  - 使用 ArrayBuffer + Blob URL 延迟加载
  - 或接入宿主提供的文件存储服务（如果有）
- **列表虚拟滚动**：笔记超过 1000 条时渲染会变慢，需实现虚拟列表

### 🔧 数据备份
- **导出/导入**：支持将整个笔记库导出为 JSON，方便迁移和备份
- **云端同步**：如果宿主支持，可对接 Supabase 或其他云存储

### 🔧 国际化
- 当前界面硬编码中文，如需支持多语言需重构为 i18n 方案

---

## 优先级排序原则

1. **高频刚需优先**：语音输入 > 双向链接（因为前者每天用，后者偶尔用）
2. **数据积累优先**：先让用户能方便地记录和整理，再考虑分析和推荐
3. **独立功能优先**：不依赖其他模块的功能更容易迭代
4. **用户可见价值优先**：周期性回顾 > 内部重构
