# 随想笔记（quick.notes）

一个「先记下、再整理」的开发想法收纳盒，可和角色一起互动。

## 它做什么

- **随手记**：新建一条想法（标题可留空），默认落在「收集箱」，不强迫你当场分类。
- **AI 归类**：一键让 AI 读完想法，给出分类 / 标签 / 一句话摘要。分类范围来自「设置」里的分类清单。
- **问角色**：选一个角色卡，让 TA 以自己的人设读完你的想法并点评、给建议、指出风险，结果存进「分析」。
- **AI 批量处理**：对收集箱里的全部想法，要么让角色整体点评，要么逐条自动归类整理。
- **分析记录**：所有角色点评 / AI 归纳都留档，可复制，也可一键「发到聊天室」继续和角色聊。
- **和宿主速记小窗共用数据**：在手机对局界面等任意位置弹出的「速记」小窗写下的内容，会直接出现在这个应用里（反之亦然）。

## 数据

- 全部数据存在浏览器 IndexedDB，不上传。
- 集合：`notes`（想法）、`analyses`（分析记录）、`meta`（分类清单与默认角色）。
- 速记小窗（宿主侧）读写的是同一份 `notes` 集合，因此两边实时同步（切换回应用时自动刷新）。

## 权限

`app.data.read/write`、`ui.toast`、`ai.classify`、`ai.chat`、`ai.generate`、`characters.read`、`chat.read`、`chat.sendMessage`、`chat.requestReply`。

## 前提

- 「AI 归类 / 归纳」需要宿主里配置了可用的模型。
- 「问角色」需要至少一张角色卡。

## 打包

```bash
node tools/build-custom-app-zip.mjs quick-notes
```

产出 `quick-notes.zip`，在「应用工坊 → 导入」安装。迭代时用应用卡片上的「换包」原地更新，数据保留。
