# 随想笔记 · 产品介绍

> 一个「先记下、再整理」的想法收纳盒，让 AI 和你喜欢的人设角色，陪你把零散灵感长成结构化的知识。

**当前版本**：v1.12　|　**运行环境**：AI 虚拟手机 · 自定义应用　|　**数据存储**：本地浏览器 IndexedDB，不上传

---

## 为什么需要它

脑子里总有很多一闪而过的念头：一个 bug 的线索、一个产品点子、一句想深入的反思。传统笔记要求你当场分类、起标题、想清楚，结果就是——懒得记，念头就丢了。

随想笔记的思路是**把「记录」和「整理」分开**：

1. 想到什么先扔进**收集箱**，一个字也行；
2. 攒够了再交给 **AI 或角色** 帮你归类、打标签、写摘要、串成网络；
3. 需要时随时**回顾、导出、备份**。

你只负责捕捉，整理交给它。

## 核心能力

### ✍️ 低摩擦记录

- **随手记**：新建一条想法，标题可留空，默认落在收集箱，不逼你当场分类。
- **速记小窗共用**：在手机对局界面等任意位置弹出的「速记」小窗写下的内容，会实时出现在这里（反之亦然），两边读写同一份数据。
- **快捷模板**：5 个预设模板（🐛 Bug 记录 / 💡 灵感想法 / ✅ 待办事项 / 🤔 反思总结 / 📚 学习笔记），一键套用结构。还能「复制 AI 提示词」发给 ChatGPT/Claude/Kimi，把它生成的 JSON 粘回来变成你自己的新模板。

### 🗂️ 智能整理

- **AI 归类**：一键让 AI 读完想法，给出分类 / 标签 / 一句话摘要。
- **智能分类**：输入分类时实时匹配已有分类，也能顺手新建，分类体系越用越顺。
- **状态管理**：收集箱 → 已整理 → 归档，三种状态用筛选 chips 随时切换查看，标记后不会再「凭空消失」。

### 🎭 角色互动（全部由你主动触发）

- **问角色**：选一张角色卡，让 TA 以自己人设读完你的想法，点评、给建议、指出风险，结果存进「分析」。
- **AI 批量处理**：对收集箱里的全部想法，要么让角色整体点评，要么逐条自动归类整理。
- **发到聊天室**：任何一条角色点评 / AI 归纳，都能一键发到聊天室，继续和角色聊下去。

### 🔗 知识网络

- **双向链接**：正文里写 `[[笔记标题]]` 就能引用另一条笔记；不想记标题？点「插入链接到笔记」，搜索/浏览选择即可。
- **智能推荐**：打开一条笔记时，系统按 6 个维度打分（同分类、标签重叠、关键词、直接链接、共同引用、时间接近）推荐最相关的其他笔记，帮你发现「原来这两件事有关」。

### 📅 回顾与洞察

- **时间线视图**：按今天 / 昨天 / 本周 / 本月 / 更早分组，带时间轴可视化；默认只展开今天和昨天，需要时再展开，长列表也不晕。
- **分组可切换**：按「更新时间」或「创建时间」分组，随你挑。
- **日历热力图**：最近 30 天的记录密度一眼看清，点某天直接跳转；也支持输入日期精确跳转。
- **周期性回顾**：周 / 月统计（记录数、分类分布等），还能让 AI 生成一段有温度的回顾总结。

### 📎 附件

- **多格式上传**：doc/docx、zip、txt、md、png、jpg 等，单文件 ≤ 5MB，每条笔记可挂多个。
- **附件 AI 分析（可选开关）**：对 txt/md 文本和图片提取关键信息，辅助分类和摘要——开关默认由你控制，避免无意义消耗 token。

### 📤 导出与备份

- **单条导出**：Markdown / TXT / JSON / ZIP 四种格式。
- **含附件只走 ZIP**：为避免把几 MB 的图片硬塞进文本导致文件打不开，带附件的笔记只允许导出 ZIP——里面是 `笔记.md` + `attachments/` 原始文件，图文完整、可长期存档。
- **批量导出**：底部常驻 ☑️ 按钮进入批量模式，勾选多条（或全选），一次性打包成 ZIP；每条笔记统一整理成「序号_标题」文件夹，按更新时间倒序，结构整齐不乱码。

---

## 数据与隐私

- 所有笔记、分析、附件都存在**浏览器本地 IndexedDB**，不上传服务器。
- 集合划分：`notes`（想法）、`analyses`（分析记录）、`meta`（分类清单与自定义模板）。
- 与宿主速记小窗共用同一份 `notes`，切回应用自动刷新。

## 使用前提

| 功能 | 需要的条件 |
|------|-----------|
| AI 归类 / 归纳 / 回顾总结 | 宿主里配置了可用的模型 |
| 问角色 | 至少一张角色卡 |
| 附件 AI 分析 | 文本类支持 txt/md；图片需模型支持视觉识别 |

**权限清单**：`app.data.read/write`、`app.manifest.read`、`ui.toast`、`ai.classify/chat/generate`、`characters.read`、`chat.read/sendMessage/requestReply`。

---

## 谁适合用它

- **开发者 / 产品**：把 debug 线索、需求灵感、待办碎片收进一个盒子，再让 AI 归位。
- **爱思考的人**：随手记下转瞬即逝的想法，周期性回顾时看见自己的思考轨迹。
- **角色卡玩家**：让喜欢的角色读你的想法、陪你把一个问题聊深。

## 安装 / 更新

```bash
node tools/build-custom-app-zip.mjs quick-notes
```

产出 `quick-notes.zip`，在「应用工坊 → 导入」安装。迭代时用应用卡片上的「换包」原地更新，**数据保留**。
